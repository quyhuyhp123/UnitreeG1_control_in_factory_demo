# Local costmap — observation only

Run `D:\unitree_g1\run_sim.bat -Factory v2 -Yolo`, or `-Rgbd -NoYolo` for geometry only. Camera debug also opens Local Costmap. Camera Save saves costmap.png, occupancy.npy, cost.npy, metadata.json and semantics.json alongside RGB-D data.

Grid: 60×60 cells, 0.1 m, 6×6 m. Rolling origin snapped to world 0.1 m lattice, centered near pelvis; axes stay aligned with world (not robot yaw). Image up = world +Y, right = +X. Gray unknown (-1), white observed free (0), red occupied (100), amber inflated (80). Inflation does not overwrite the raw occupancy array. Radius 0.62 m = Factory V2 body radius 0.45 + sway 0.08 + pose error 0.04 + margin 0.05; circular kernel includes cell centers within radius.

Finite depth rays produce observed free cells up to returns, obstacle endpoints occupied. Invalid/out-of-range rays clear nothing. Reuses stage 4 floor removal and acquisition-time robot self AABBs; valid floor returns can clear observed floor. High returns above world Z=2 m do not clear space beneath. Projection of 3D rays to 2D is conservative only to a limited extent: rays passing above small obstacles can still over-clear; this is NOT validated collision avoidance. Unknown behind occlusions remains unknown unless previously observed; evidence expires after 2 s acquisition wall timestamp. No inference that the rear blind spot is free. Retained samples are world-grid keyed so robot turns do not rotate old obstacles. Memory is spatially bounded; backwards timestamps clear history. Semantic labels are optional, timestamp-expiring world-cell annotations from actual stage 4 YOLO localization, and never make cells free.

Allowed/Forbidden polygons are read unchanged from configs/navigation_map_v2.json. Outside allowed area/inside forbidden area is occupied and cannot expire or be ray-cleared. Static collider AABB projections are also overlaid at sensor enable, excluding floor, robot, high roof and directly dynamic bodies. These are explicitly map priors, NOT AI detections. AABBs overapproximate geometry and can close tight passages; bodies nested under a dynamic ancestor need further filtering before use in dynamic scenes. Static factory modifications require sensor restart to recache. Circular inflation also applies to these priors.

Files: controllers/local_costmap.py (new), scripts/test_costmap_logic.py (new), controllers/rgbd_camera.py (camera lifecycle, update/save), controllers/factory_g1_runtime.py (optional semantic annotations), README and this report. No navigation consumer, velocity output, dynamic avoidance, route/config edits, commit or push. Geometry runs on acquisition thread: no real-time performance guarantee. Preview reduced to 240×240; saved image 600×600. Final depth stride 16 pixels may miss narrow obstacles. Depth-only map still works when YOLO is disabled. Set stage 4 localization enabled=false to skip costmap acquisition along with localization.

Tests: `scripts/test_costmap_logic.py` checks replayed measured RGB-D, unknown/occupied/inflation, expired free evidence and persistent static restrictions. Live camera test derived from test_yolo_live.py adds 100 W control ticks and saves costmap_slow_walk; existing tests/routes are unchanged. See measured results in docs/local_costmap_results.md. Neither synthetic/replay tests nor completion of a motion sequence proves safe path planning.
